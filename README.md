1) BanID - desktop-приложение на WPF для управления банковскими счетами
и заявками пользователей. Реализует авторизацию с капчей, регистрацию,
личный кабинет с отображением персональных данных и счёта, отправку
заявок на банковские операции и печать выписки.
2) Визуальная демонстрация
Страница LoginPage
 
Страница RegPage
 
Страница UsingCabinet
 
3) Установка
Требования
	Windows 10/11
	Visual Studio 2019/2022 с workload
	.NET Framework 4.7.2 или выше
	SQL Server (LocalDB или Express) с базой BanIDBase
4) Использование
1. Запуск Открывается окно MainWindow с LoginPage.
2. Регистрация, Кнопка «Регистрация», заполнить логин, пароль, ФИО, паспорт, «Зарегистрироваться». Персональные данные шифруются перед сохранением в БД.
3. Авторизация Ввести логин, пароль и защитный код (капчу), нажать «Войти».
4. Личный кабинет
	Просмотр персональных данных (расшифровка на лету).
	Просмотр номера счёта, остатка и валюты.
	Выбор типа заявки из списка и отправка её в БД.
	Кнопка «🖨 Печать выписки» - отправка области `PrintArea` на принтер.
5. Выход Кнопка «Выход» возвращает на страницу авторизации.
5) Структура
6)Данные
Users – (ID, Login, Password, EncryptedData, Role) Пользователи системы.
Accounts – (ID, UserID, AccountNumber, Balance, Currency) Банковские счета.
Requests – (ID, UserID, RequestType, Status, CreatedAt) Заявки пользователей.7
